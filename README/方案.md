## SV-Flow: Lightweight Inference-Time Diversity Enhancement for Structure-Based Drug Design via Kinematic Decoupling

**一句话定位**：SV-Flow 提出了一种轻量级的推理期多样性增强框架——通过运动学解耦将SVGD互斥限制在质心空间，在保护化学完整性的前提下，实现结合模式的空间多样性提升。

### 核心叙事："Less is More"

我们最初设计了切平面投影（TP）和正交动能保护（OP）作为"物理护栏"，期望它们在排斥分子的同时保护化学键和避免位阻。然而，系统性消融实验揭示了**反直觉的事实**：这两个约束严重破坏了空间多样性（质心方差降至基线的 29%）。移除它们后，纯SVGD互斥恢复了全部探索能力（2.44x 提升），同时化学完整性与基线相当。这一"少即是多"的发现，为推理期引导提供了简洁有效的设计原则。

### 1. Introduction (引言)

**(第一段：大背景——SBDD需要多样化结合模式)** 基于结构的药物设计（SBDD）旨在发现能与靶点蛋白高亲和力结合的新型小分子。近年来3D扩散模型和流匹配模型（DrugFlow, TargetDiff等）取得了突破性进展。然而，真实的药物发现需要探索蛋白质口袋中**多样化的结合模式（Diverse Binding Modes）**——不同配体占据不同子口袋，获得独特药理学性质和专利空间。

**(第二段：模式坍塌困境)** 现有流匹配模型在独立重复采样时面临严重的模式坍塌：分子高度同质化、扎堆于口袋中心，错失探索长尾构象空间的机会。

**(第三段：现有方案缺陷——Metadiffusion的物理灾难)** Metadiffusion（Ong et al., 2026）通过全原子RMSD启发式排斥增强多样性，但直接在全原子坐标（ℝ³ᴺ）施加各向同性距离惩罚，剧烈扭曲流匹配轨迹，导致分子键断裂和蛋白质位阻。**关键洞察**：全原子互斥在小分子SBDD中存在根本性缺陷——它向分子内部构象自由度注入破坏性动能，而小分子的化学完整性远比蛋白质构象脆弱。

**(第四段：SV-Flow方案——质心空间的轻量级互斥)** 我们提出SV-Flow：将独立ODE升级为耦合多粒子变分推断系统。核心设计包含**三个轻量级机制**：
1. **运动学解耦**（§4.1）：将速度场分解为v_int（内部构象）和v_CoM（质心平移），SVGD仅作用于v_CoM
2. **SVGD核互斥**（§4.2）：在ℝ³质心空间通过RBF核+Stein算子最大化分布熵
3. **时间退火调度**（§4.5）：晚期介入（t ≤ 0.5），避免早期噪声态引入伪影

**(第五段：关键发现——"Less is More"）** 我们最初也设计了切平面投影和正交动能保护作为"安全护栏"。但系统性消融实验揭示：**这些约束严重破坏空间多样性**。移除它们后，纯SVGD互斥恢复了2.44倍空间多样性，同时化学完整性与基线相当。这颠覆了"越多约束越安全"的直觉。

**(第六段：贡献总结）**
1. **方法创新**：首次将SVGD交互框架与流匹配ODE耦合，通过运动学解耦将互斥限制在质心空间（ℝ³），从数学上保证化学键零影响
2. **实验发现**：系统性消融揭示"过度约束反而破坏多样性"——"Less is More"设计原则
3. **实用性**：在保持化学完整性的同时，以O(N²·3)的极低计算开销提升空间多样性。对比事后平移基线，证明推理期干预的必要性

### 4. Methodology: Stein Variational Flow Matching (SV-Flow)

SV-Flow将独立的单粒子ODE积分重构为耦合多粒子交互动力学系统。核心包含三个轻量级机制。

#### 4.1 运动学解耦 (Kinematic Decoupling) ← 核心创新

将全原子速度场v_θ严格正交分解：
$$v_\theta^{(i)} = v_{int}^{(i)} + v_{CoM}^{(i)}$$

- **v_int**：内部构象速度（零质心运动），完全由基座模型接管
- **v_CoM**：质心平移速度（ℝ³，广播至所有原子），是SVGD的作用目标

**设计原则**：SVGD互斥**仅作用于v_CoM**。v_int保持完全纯净，从数学上保证对分子内部化学键的**零诱导应变**。

#### 4.2 SVGD核互斥（质心空间） ← 核心创新

在预测干净分子的质心空间（ℝ³）中定义SVGD互斥速度增量：

$$\Delta V_{SVGD}^{(i)} = \frac{1}{N} \sum_{j \neq i} \left[ k(\mathbf{c}^{(j)}, \mathbf{c}^{(i)}) \nabla_{\mathbf{c}^{(j)}} E_{rep} + \nabla_{\mathbf{c}^{(j)}} k(\mathbf{c}^{(j)}, \mathbf{c}^{(i)}) \right]$$

- 左项：核加权排斥梯度 → 分子质心相互远离
- 右项：Stein算子（核梯度）→ 驱动系统向香农熵最大化演化
- 核函数：RBF径向基核，带宽采用中位数启发式自适应确定
- **关键保证**：ΔV_SVGD是纯ℝ³向量，完全不接触v_int

**与Metadiffusion的本质区别**：

| 维度 | Metadiffusion | SV-Flow |
|------|--------------|---------|
| 互斥空间 | 全原子 ℝ³ᴺ | 质心 ℝ³ |
| 对化学键的影响 | 有破坏风险 | **零影响（数学保证）** |
| 计算开销 | O(N²·N_atoms²) | O(N²·3) |
| 适用场景 | 蛋白质构象生成 | **小分子SBDD** |

#### 4.3 时间退火调度 ← 实验证明必要

$$\lambda(t) = \begin{cases} 0, & t > t_{on} \\ \lambda_{max} \cdot (1 - t/t_{on})^2, & t \leq t_{on} \end{cases}$$

- t_on = 0.5：前半程关闭互斥，允许构建化学拓扑骨架
- 后半程抛物线渐变开启，λ_max=1.0

#### 4.4 关于切平面投影和正交动能保护的反直觉发现

我们最初设计了两个几何约束机制（详见附录A消融实验）：
- **切平面投影（TP）**：将互斥速度投影到蛋白表面切平面
- **正交动能保护（OP）**：滤除与v_CoM平行的分量

**关键实验发现**：这两个约束**严重破坏空间多样性**。
- SV-Flow FULL（含TP+OP）：空间多样性仅为DrugFlow的29%
- SV-Flow Core（移除TP+OP）：空间多样性恢复至DrugFlow的71%（2.44x提升）
- 化学完整性与基线相当（clashes: 1.40 vs 1.15, bond anomaly: 5.1% vs 2.7%）

**结论**：纯SVGD互斥 + 时间退火即是最优解。约束越少，效果越好。

#### 4.5 最终算法

```
Algorithm: SV-Flow Core Sampling

Input: protein pocket P, N trajectories, T steps
Output: N diverse molecules

for t in 0 → 1 (DrugFlow convention):
    # 1. Batched forward pass
    v_θ = model.predict(x_t, t, P)  # (ΣN_atoms, 3)
    
    # 2. Kinematic decoupling
    v_CoM = per_molecule_mean(v_θ)  # (N, 3), broadcast to atoms
    v_int = v_θ - v_CoM
    
    # 3. SVGD repulsion (late-onset only)
    if t_sv <= t_on:  # t_sv = 1 - t (SV convention)
        c = predict_clean_COM(x_t)
        ΔV = SVGD_repulsion(c, kernel='RBF', h='median')
        ΔV = λ(t_sv) · ΔV  # time annealing
    else:
        ΔV = 0
    
    # 4. ODE step (NO projection, NO orthogonalization)
    x_{t+dt} = x_t + dt · (v_int + v_CoM + ΔV_broadcast)

Note: v_int is NEVER modified by guidance.
```

### 5. Experiments (实验)

#### 研究问题

1. **空间多样性提升**：SV-Flow Core能否在保持化学完整性的前提下提升空间多样性？
2. **推理期干预 vs 事后平移**：生成过程中的协同调整是否优于事后平移+最小化？
3. **"漂移"辨析**：DrugFlow的高质心方差是否来自有效的结合模式探索，还是仅仅偏离了结合位点？

#### 5.1 Experimental Setup

**数据集**：CrossDocked2020测试集（100个过滤口袋）
**基座模型**：DrugFlow（heterogeneous GVP-GNN），checkpoint 161MB
**采样参数**：N=10, T=500, λ_max=1.0, t_on=0.5
**硬件**：NVIDIA RTX 5090 (32GB VRAM)

**对比方法**：
1. DrugFlow（独立采样，无SVGD）
2. DrugFlow N=50 + MaxMin后处理（多样性筛选基线）
3. 事后平移基线（DrugFlow生成 → 质心平移 → 能量最小化）
4. SV-Flow Core（本文方法：运动学解耦 + SVGD + 时间退火）

**评价指标**：
- 化学质量：QED, SA Score, MW, 有效性
- 化学多样性：Tanimoto多样性（1 - 平均配对相似度）
- 空间多样性：质心方差, 平均配对质心距离, 距口袋中心距离
- 物理合法性：Clashes/mol, Bond Anomaly Rate, Broken Rings/mol
- 对接亲和力：Vina/Gnina对接得分
